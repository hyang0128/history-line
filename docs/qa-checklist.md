# 浏览器回归 QA 清单

> 目标：把 A2（时间轴）、A3（搜索/筛选/主题）、A4（发布模式/主题/挂载）遗留的「沙箱无法实测」交互项过一遍。
> 环境：本地 `npm run dev` 后浏览器打开，生产对照可用 `npm run build:local && npm run preview`。
> 记录每条「通过 / 不通过」，不通过的把复现步骤与控制台报错贴回会话。

## 0. 启动

- [ ] `npm run dev` 启动成功；访问 `http://localhost:4321/history-line/`（base 含 history-line 前缀）。
- [ ] 页面顶部出现红色「本地预览模式：含未审核（draft）」横幅（本地构建应出现）。

## 1. 时间轴（A2）

- [ ] 首页时间轴加载：滚轮缩放平滑、拖拽平移跟手、无卡顿跳变。
- [ ] `?mock=3000&hud=1` 下 3000 节点实测帧耗时（右上角 HUD）绝大多数 <16ms。
- [ ] 语义缩放：最缩小只见 importance=5 节点；逐档放大逐步显示更多级。
- [ ] 四轨道开关（事件/人物/专题/世界史）生效，可单独关。
- [ ] 顶部朝代快捷条点击 → 时间轴跳到该朝代；分期色带可点击。
- [ ] 键盘：← → 平移，+ − 缩放，Home 回全览。
- [ ] 点击节点弹出详情面板：三 tab（正史/野史/批注）切换正常、可信度徽章显示、quote 折叠展开、draft 节点有 draft 徽章。
- [ ] 深链：在时间轴上定位某节点后 URL hash 形如 `#t=700..800&n=…`；刷新页面回到同一位置。
- [ ] 节点页「在时间轴中查看」链接从 `/event/xxx` 跳回时间轴并定位。

## 2. 搜索（A3）

- [ ] `/search` 输入"安史"实时出结果，标题/概述命中；输入"资治通鉴"能命中出处，结果显示「出处 · 《资治通鉴》…」。
- [ ] 多词 AND：输入「长安 叛乱」结果收窄到同时命中者。
- [ ] 命中词有 `<mark>` 下划线高亮；一条都没有时给出提示。
- [ ] 类型/可信度/含未审核筛选与关键词叠加生效；结果数统计正确。
- [ ] URL 同步：搜索中 URL 出现 `?q=..&type=..&cred=..&drafts=0`；改动后浏览器后退能恢复之前筛选。
- [ ] 复制带参数 URL 到新标签页，能还原到相同结果。

## 3. 筛选（A3）

- [ ] 首页「节点目录」筛选条：类型/可信度/标签切换即时生效，空分期/朝代块收起。
- [ ] 首页筛选状态写入 URL（如 `/history-line/?type=event&cred=A`），刷新与后退恢复。

## 4. 主题（A3/A4）

- [ ] 头部 ☀/☾ 按钮循环：跟随系统 → 亮 → 暗；选择后整页（含时间轴节点颜色、画布底色）立即换色。
- [ ] 刷新页面后主题保持（localStorage）；首屏无闪白/闪黑。
- [ ] 时间轴画布在切换主题时同步重绘，不残留旧色。

## 5. 发布模式（A4）

- [ ] `npm run build`（生产）后 `npm run preview` 访问：无预览横幅；draft 节点（如 `sui-founding`）返回 404 或不存在于目录/时间轴/搜索。
- [ ] `npm run build:local` 后 preview：横幅出现，draft 可见。

## 6. 移动端（A3）

- [ ] 窄屏（DevTools 模拟 375px）：头部导航换行不重叠、主题按钮可点；筛选条与搜索框可用；时间轴单指拖动不造成整页误滚动（如受影响属已知限制，记录即可）。
- [ ] 目录列表年份列在小屏不换行错位。

## 7. 通用

- [ ] 浏览器控制台无红色报错（fetch 失败、null 读取等）。
- [ ] 样式加载正常（无 404 的 CSS/JS）。
- [ ] 各页面（/、/search、/about、/era/tang、/event/an-lushan-rebellion）可正常浏览与互链。

- [ ] 城市点 hover 显示「地名（N 条节点提及）」工具条；`/map?dyn=tang` 深链直选唐朝。
- [ ] 右侧列表列出该朝节点（年份升序），点击跳转对应节点页。
- [ ] 切换暗色主题后地图配色（背景/边界/城市点）同步变化。
- [ ] 生产构建下地图只显示 reviewed 节点相关城市；本地构建包含全部。

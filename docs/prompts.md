# 提示词演进记录

## v0.1 · 2026-09-17 · 规划会话

来源：在 Claude Code 会话中手写 10 个唐朝事件 + 1 个人物样例后归纳。

观察到的问题与对应规则：

- 写批注时容易凭印象给出卷次，实际核对时有几处（王夫之《读通鉴论》、赵翼《廿二史札记》条目名）没有把握，因此规则 1 要求不确定时写"待核"而不是猜。
- 以英文引号开头的 YAML 值会导致解析失败（黄巢起义 note、开元盛世杜甫诗），因此加规则 10。
- 文学作品（杜甫诗、《秦妇吟》）放在野史块时需要明确标注性质，否则会被当作史料。
- AI 综述如果不强制"共识 / 分歧"结构，容易写成模糊的总结。
